Your First Project

Pick one project and finish it before starting another. The media server is the easiest start. The game server adds one router change, so do it second.

Media server

Difficulty: Easy - Time: about 1 hour

Jellyfin is a free media server. It streams the movies, shows, and music on your server to any phone, TV, or browser in your home.

Before you start

Read Stay Safe before you open any port to the internet.

  1. Update the system

    sudo apt update && sudo apt upgrade -y

  2. Install Jellyfin

    Run the install script from official docs (external site) 

    curl https://repo.jellyfin.org/install-debuntu.sh | sudo bash

  3. Open the dashboard

    On another device, go to http://SERVER-IP:8096. Replace SERVER-IP with your server's address, then follow the setup wizard to add your first media folder.

Game server

Difficulty: Medium - Time: about 2 hours

A dedicated server keeps your world online so friends can join even when you're not playing.

Warning

Forward only the one port your game needs. Never forward your router's admin page or every port on the server.

  1. Install the server

    Every game has its own dedicated server. Follow your game's official server guide and run it on the same machine as your media server. Write down the port and protocol (UDP or TCP) the guide lists.

  2. Forward one port

    In your router's settings, give the server a reserved IP address, then forward only that one port to it. On an AT&T gateway it's under Firewall, then NAT/Gaming.

  3. Test from outside

    Ask a friend on a different network to join with your public IP address. If they can't connect, check the server's firewall before you open anything else.
