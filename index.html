Media server

Difficulty: Easy - Time: about 1 hour

Before you start

Read Stay Safe before you open any port to the internet.

  1. Update the system

    sudo apt update && sudo apt upgrade -y

  2. Install Jellyfin

    Run the install script from official docs (external site) 

    curl https://repo.jellyfin.org/install-debuntu.sh | sudo bash

  3. Open the dashboard

    On another device, go to http://SERVER-IP:8096.

Screenshot figure: forward one port

For a game server, friends outside your network need one port forwarded to the server. On an AT&T gateway it's under Firewall, then NAT/Gaming.
